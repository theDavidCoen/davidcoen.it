This tool allows you to generate a BIP321-compliant Bitcoin URI that can combine multiple types of Bitcoin-related payment addresses in a single shareable link.

You can include:

  • A standard Bitcoin address
  • An ARK address (e.g., ark1...)
  • A BOLT12 Lightning offer (e.g., lno1...)
  • A Silent Payment address (e.g., sp1...)
Once generated, you can share this BIP321 URI directly, or use it to create a BIP353-compatible Lightning Address below.













BIP353 DNS TXT Record Generator

This section helps you generate a DNS TXT record that links a Lightning Address (e.g., alice@yourdomain.com) to your BIP321 URI, following BIP353.

Note: In order for your Lightning Address to work, your domain must have DNSSEC enabled. DNSSEC is a security extension that ensures the integrity of DNS records.

How to enable DNSSEC: Most domain registrars (like Namecheap, GoDaddy, Cloudflare, etc.) offer DNSSEC setup in their DNS management dashboard.
Here an example guide from Supporthost: https://supporthost.com/tutorial/enable-dnssec/
